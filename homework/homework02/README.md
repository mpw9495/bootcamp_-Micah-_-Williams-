# Homework 02 — Tooling Setup

This homework focuses on setting up a reproducible Python project environment and project structure. I practiced creating and managing an isolated Python environment, installing required packages, organizing a project using a standard folder structure, managing environment variables and secrets with a `.env` file, creating a reusable configuration helper, verifying the project setup using Jupyter and NumPy, recording project dependencies in a `requirements.txt` file, and using Git and GitHub for version control.
